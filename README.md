> Portfolio web moderno e interactivo desarrollado con **Next.js 14 (App Router)**, **TypeScript** y **Tailwind CSS**. Diseñado para mostrar proyectos, habilidades técnicas, trayectoria formativa (3 titulaciones FP: SMR, DAM, DAW) y experiencia laboral.

---

## ✨ Características Principales

- 🌐 **Soporte Multi-idioma (i18n)**: Español (`ES`), Català (`CA`) e Inglés (`EN`) con cambio instantáneo de contexto.
- 💻 **Terminal Interactiva**: Terminal integrada con autocompletado y comandos (`help`, `skills`, `projects`, `education`, `cv`, `clear`, etc.).
- 📄 **Descarga Oficial de CV**: Acceso directo al currículum oficial en PDF desde el Hero, Sobre mí y la barra de navegación.
- 🎨 **Diseño Moderno & Dark Mode**: Efecto de partículas dinámico, microinteracciones, glassmorphism y animaciones fluidas con Framer Motion.
- 📱 **Modales de Proyectos en 2 Columnas**: Vista detallada con capturas visuales, retos técnicos, arquitectura y enlaces directos a código/demos.
- 📱 **100% Responsive**: Optimizado para dispositivos móviles, tablets y monitores de alta resolución.

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/Peke2005/Porfolio.git
   cd Porfolio
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Ejecutar en entorno de desarrollo**:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

4. **Compilar para producción**:
   ```bash
   npm run build
   npm run start
   ```
